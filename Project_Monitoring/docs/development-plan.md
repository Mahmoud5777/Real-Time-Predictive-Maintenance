# Mini-Project 4 — Development Plan

## Week 1 — Architecture and Preparation
- Define the global architecture.
- Prepare the frontend structure.
- Document API requirements.
- Create representative mock data.

## Week 2 — React Dashboard
- Build the main layout.
- Create machine monitoring components.
- Display predictions and alerts.
- Create Fog node monitoring views.

## Week 3 — Backend Integration
- Connect React to the Cloud REST API.
- Retrieve machines, measurements and predictions.
- Display alerts, Fog nodes and task events.
- Handle API errors and loading states.

## Week 4 — Observability
- Configure Prometheus metrics.
- Configure Grafana dashboards.
- Monitor application and Fog performance.

## Week 5 — DevOps
- Create Docker configuration.
- Configure Docker Compose.
- Create GitHub Actions CI workflow.
- Automate frontend checks and builds.

## Week 6 — Testing and Demonstration
- Test the complete dashboard.
- Validate integration with all mini-projects.
- Fix errors.
- Prepare documentation and project demonstration.
