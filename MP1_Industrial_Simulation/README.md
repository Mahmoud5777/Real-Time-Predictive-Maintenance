# MP1 - Industrial Simulation

Ce dossier contient les éléments du mini-projet 1 de la plateforme Collaborative Fog Computing for Real-Time Predictive Maintenance.

## Objectif

Simuler un environnement industriel et produire des données représentatives pour le système de maintenance prédictive.

## Contenu

- `simulate.py` : script de simulation industrielle.
- `contracts/` : contrats et exemples de messages utilisés pour l'intégration.
- `docs/` : architecture et documentation technique.
- `infra/` : configuration Mosquitto.
- `Cahier_des_charges_Projet.pdf` : cahier des charges du projet.

## Intégration

Les formats des messages doivent rester compatibles avec les contrats partagés avec les autres mini-projets.

Le backend Cloud MP3 est maintenu séparément dans `MP3_Backend_Source/`.
